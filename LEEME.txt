PORTAFOLIO DE DAVID
Proyecto personal, solo local. No se ha publicado.

CÓMO ABRIRLO
Abre index.html con tu navegador, o ejecuta: node servir.cjs (también npm start).
Visita http://localhost:8080. Ctrl+C detiene el servidor.
El servidor solo escucha en 127.0.0.1.
Incluye fuentes, imágenes, iconos, GSAP 3.15.0 y ScrollTrigger como archivos
locales. No necesita npm install para visualizarlo. Los enlaces externos,
WhatsApp y correo requieren las aplicaciones o servicios correspondientes.

DEPENDENCIAS DE DESARROLLO
GSAP se instala mediante npm como librería oficial; no es un CLI ni un MCP.
Para reconstruir los archivos locales desde las versiones fijadas:
  npm ci --ignore-scripts
  npm run assets
Para comprobar sintaxis JavaScript: npm run check
No incluyas node_modules al comprimir el proyecto; assets/vendor y assets/icons
ya contienen lo necesario para que la web funcione.

PUBLICAR DESDE TU CUENTA PERSONAL
1. En GitHub, inicia sesión con tu cuenta personal y crea un repositorio
   llamado portafolio-david. Comprueba que el propietario sea tu usuario personal.
2. Sube el contenido de esta carpeta extraída, no el ZIP. index.html y assets/
   deben quedar en la raíz del repositorio. No subas node_modules/.
3. En tu cuenta personal de Vercel, importa ese repositorio desde GitHub.
   Configuración para este proyecto estático:
   - Framework Preset: Other.
   - Root Directory: raíz del repositorio (./).
   - Build Command: activar Override y dejarlo vacío.
   - Output Directory: . (un punto).
   - No requiere variables de entorno.
4. Pulsa Deploy y comprueba la dirección que te entrega Vercel.
No ejecutes npm start como comando de construcción en Vercel; solo sirve
para la vista previa local. El formulario seguirá preparando borradores
de WhatsApp o correo; no requiere un servidor propio.
Documentación: https://vercel.com/docs/builds/configure-a-build
